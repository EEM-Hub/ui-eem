## Cognitive Load Theory: Types, Measurement, and Instructional Design Implications

Cognitive load refers to the total effort being used in working memory at any given time. Developed by John Sweller in the late 1980s from research on problem solving, cognitive load theory (CLT) provides a framework for instructional design based on the principle that learning improves when instruction accounts for the severe capacity and duration limits of working memory. The theory identifies three interacting types of cognitive load and has generated numerous empirically validated instructional effects.

## Key Concepts

- **Working memory** is extremely limited in both capacity (roughly 7 +/- 2 chunks, per Miller's 1956 finding) and duration; these limits can impede learning under certain conditions.
- **Intrinsic cognitive load** is the inherent difficulty of the material itself, determined by element interactivity; it cannot be altered by instruction but can be managed by breaking schemas into subschemas taught in isolation.
- **Extraneous cognitive load** is imposed by how information is presented (instructional format); it is under the designer's control and should be minimized.
- **Germane cognitive load** is the working memory effort the learner dedicates to processing intrinsic load and constructing schemas; it is not an independent source of load but reflects the resources remaining after extraneous load is subtracted. High intrinsic + low extraneous = high germane = better learning.
- The three load types were originally treated as additive, but current research suggests they circularly influence each other, and the additivity hypothesis is questioned.
- **Schemas** are the primary unit of analysis in CLT — organized knowledge structures stored in long-term memory that reduce working memory demands for experts.
- The classic Atkinson-Shiffrin "gateway" model held that all long-term encoding passes through working memory, but modern research shows some long-term memory can be encoded in parallel with or bypassing working memory.
- **Expertise reversal effect**: instructional techniques that help novices can become counterproductive for experts, because experts' existing schemas make the additional guidance redundant and therefore extraneous.
- Heavy cognitive load increases errors, stereotyping (via automatic schema/pattern activation), and fundamental attribution error frequency.
- The **Google effect** (digital amnesia): people forget information they expect to find online, prioritizing retrieval location over deep encoding.
- AI tools may cause **deskilling** — a study showed poorer surgical outcomes when physicians' AI tool was discontinued.

## Commands and Syntax

- **Relative Condition Efficiency** (Paas & Van Merriënboer, 1993):
  - Formula: `(Z_performance - Z_mental_effort) / sqrt(2)`
  - Used to compare instructional conditions by combining performance scores with subjective mental effort ratings.
- **Measurement approaches**:
  - Subjective: self-reported mental effort rating scales
  - Physiological: task-invoked pupillary response (pupil dilation correlates with high cognitive load), heart rate, blood pressure, respiratory rate, eye gaze
  - Rate-Pressure Product (RPP): heart rate x blood pressure, used in ergonomic contexts for both cognitive and physical workload
  - Different measures respond differently to intrinsic, extraneous, and germane load (Deleeuw & Mayer, 2008)

## Relationships

- **Instructional design**: CLT directly informs how educational materials should be structured — minimize extraneous load, manage intrinsic load through sequencing, maximize germane processing.
- **Empirically derived effects** from CLT:
  - *Worked-example effect*: studying worked examples outperforms conventional problem solving for novices
  - *Split-attention effect*: integrating multiple information sources reduces extraneous load vs. requiring learners to mentally integrate them
  - *Modality effect*: presenting information across visual and auditory channels expands effective working memory capacity
  - *Completion-problem effect*: partially completed problems reduce load while maintaining active processing
  - *Expertise reversal effect*: techniques beneficial for novices become detrimental for experts
- **Problem solving**: means-ends analysis consumes working memory that could otherwise be used for schema construction; goal-free problems are preferred.
- **Transactive memory theory**: the internet extends group knowledge distribution, with individuals remembering where to find information rather than the information itself.
- **Desirable difficulty** (education): productive struggle that taxes working memory actually facilitates deeper learning — reducing all cognitive load is not the goal; reducing *extraneous* load is.
- **Social facilitation / audience effect**: cognitive load contributes to the overload hypothesis — performance degrades on complex tasks in the presence of an audience.

## Exam-Relevant Points

- Three types of cognitive load: intrinsic (material difficulty), extraneous (presentation format — designer-controlled), germane (learner effort toward schema construction). Know the distinction and that they are no longer considered purely additive.
- Miller's magic number: 7 +/- 2 items in short-term memory (1956).
- Simon and Chase (1973) introduced the term "chunk" for memory organization.
- Sweller developed CLT in the late 1980s from problem-solving research; Chandler and Sweller (early 1990s) introduced the terms intrinsic and extraneous cognitive load.
- Germane load is not independent — it is the portion of working memory resources available after extraneous demands are met, given constant motivation.
- Worked examples are the most efficient instructional condition, followed by completion problems, then discovery practice (Paas & Van Merriënboer).
- Expertise reversal effect: what helps novices can hurt experts — instructional strategies must adapt to learner expertise level.
- Extraneous load should be minimized especially when intrinsic load is high.
- Schemas can be broken into subschemas and taught separately to manage intrinsic load.
- Expert-novice differences: experts have schemas that reduce cognitive load for domain tasks; novices lack these and bear heavier load.
- Individual differences matter: elderly show balance disturbances under high cognitive load; children's load decreases as they develop metacognition and content knowledge; socioeconomic factors affect baseline cognitive load in children.
- Task-invoked pupillary response is a reliable physiological measure of cognitive load.
- Digital environments both reduce load (cognitive offloading, well-designed interfaces) and increase it (information overload, media multitasking, attention fragmentation).
