## Mobile Web: Browser-Based Services on Mobile Devices

The mobile web refers to World Wide Web services accessed through mobile browsers on devices such as smartphones, tablets, laptops, smartwatches, and other portable hardware via mobile or wireless networks. This page traces the history from early WAP-based access in the late 1990s through the dominance of mobile traffic over desktop, covering standards, growth patterns, technical limitations, and initiatives like AMP and Progressive Web Apps.

## Key Concepts

- **Mobile web** = browser-based web access on mobile devices over wireless/mobile networks — distinct from native mobile apps
- Mobile devices surpassed desktop for global web traffic around 2014–2015; as of April 2015, mobile accounted for 63.3% of all global web traffic
- **GSMA estimate**: 5.34 billion mobile web users as of 2025 (~60% of world population)
- **Progressive Web Apps (PWAs)** have emerged since 2017, delivering app-like experiences (offline support, push notifications, rich interactivity) within mobile browsers
- The line between mobile web apps and native apps is blurring as browsers gain hardware access (accelerometers, GPS, persistent storage)
- **WAP Forum** (1997): founded by Unwired Planet, Nokia, Ericsson, Motorola to standardize early mobile web; made obsolete by faster networks and modern smartphones
- **First commercial mobile web access**: 1996, Finland, Nokia 9000 Communicator on Sonera/Radiolinja networks
- **First mobile-specific browser service**: 1999, Japan — i-mode by NTT DoCoMo
- In many developing regions (India, South Africa, Indonesia), mobile is the *first* internet experience, not a second screen

## Commands and Syntax

- **Markup languages used**: XHTML (Extensible Hypertext Markup Language), WML (Wireless Markup Language) for lightweight mobile pages; modern mobile browsers support full HTML5
- **AMP (Accelerated Mobile Pages)**: Google's open-source framework (announced 2015) with three components:
  - **AMP HTML** — restricted HTML subset for fast rendering
  - **AMP JS** — JavaScript library managing resource loading
  - **Google AMP Cache** — CDN for cached AMP pages
- **W3C mobileOK Scheme**: validation tool to assess content readiness for mobile web
- **MobiReady Report** (by mTLD/.mobi registry): free tool to analyze mobile readiness of websites
- **Tethering**: using a mobile broadband modem to share cellular internet connection with other devices

## Relationships

- **Mobile browser** — the client software that renders the mobile web (Opera Mini, Safari Mobile, Chrome Mobile, etc.)
- **Responsive web design** — design approach enabling pages to adapt to varying screen sizes, reducing need for separate mobile sites
- **.mobi TLD** — top-level domain specifically for mobile-optimized sites; criticized by Tim Berners-Lee as fragmenting the web
- **Native mobile apps vs. mobile web apps** — competing paradigms converging as browser capabilities expand
- **W3C Mobile Web Initiative (MWI)** — standards body developing best practices and device description repositories
- **Wireless Application Protocol (WAP)** — early middleware standard for mobile web, predecessor to modern mobile browsing
- **Network generations (2G through 5G/6G)** — bandwidth evolution directly enables richer mobile web experiences
- **i-mode** — Japan's pioneering mobile internet service, a precursor to the modern mobile web

## Exam-Relevant Points

- Mobile surpassed desktop web traffic globally around 2014–2015
- First commercial mobile web: **1996, Finland** (Nokia 9000 Communicator)
- First mobile-specific browser service: **1999, Japan** (i-mode, NTT DoCoMo)
- **WAP Forum** founded **1997** by Unwired Planet, Nokia, Ericsson, Motorola
- **5.34 billion** mobile web users worldwide as of 2025
- Tim Berners-Lee criticized .mobi TLD for "breaking the Web in a fundamental way" by splitting content across device-specific domains
- Key mobile web limitations: small screens, navigation difficulty, limited JavaScript/cookie support on older devices, speed constraints, cost of data
- **AMP** requires canonical page content to match AMP content (as of February 2018)
- W3C's **Mobile Web Initiative** focuses on standards for device-appropriate data formats and content delivery
- PWAs represent the convergence of web and native app capabilities, supported by modern standards and 5G connectivity
