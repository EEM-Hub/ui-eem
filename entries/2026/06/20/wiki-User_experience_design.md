## User Experience Design (UXD) — Discipline Overview

User experience design (UX design, UXD, UED, or XD) is a user-centered design discipline focused on shaping all aspects of a user's perceived experience with a product or service — including usability, usefulness, desirability, brand perception, and overall performance. Unlike UI design, which addresses only the computer interface, UX design encompasses the entire interaction between a user and a company's products and services. It is rooted in human factors and ergonomics, and sits within the broader domain of customer experience (CX).

## Key Concepts

- **Don Norman** coined the term "user experience" in the early 1990s, arguing that "human interface" and "usability" were too narrow.
- UX design is driven by **research, data analysis, and test results** — not aesthetic preferences or opinions.
- **UX ≠ UI**: UI design is a subset; UX encompasses all perceived aspects of interaction with a product.
- **Usability** is necessary but not sufficient for a positive user experience — it is a subset, not a synonym.
- UX design is also a component of **customer experience (CX)**, covering all design stages around a customer's journey.
- **Personas**: composite user archetypes based on observed behavior patterns; used to think about user goals in specific contexts.
- **Pixel perfect**: the standard that a digital product appears exactly as the designer intended, at the pixel level.

## Core Elements (Sub-disciplines)

- **User Research** — systematic study of target users via interviews, surveys, field studies, contextual inquiry; grounds decisions in evidence rather than assumptions.
- **Visual Design** — aesthetics and look-and-feel; draws on Gestalt psychology and visual perception principles.
- **Information Architecture (IA)** — structuring and organizing information to support usability and findability; includes page structure, navigation, and metadata.
- **Interaction Design (IxD)** — designing product behavior to produce efficient, delightful experiences; has evolved from specifying UI components to designing contextual interfaces.
- **Usability** — effectiveness, efficiency, and satisfaction with which specified users achieve specified goals in a specified context (ISO 9241-11 definition).
- **Accessibility** — ease of reach, use, and understanding; WCAG principles: **POUR** (Perceivable, Operable, Understandable, Robust).
- **Human-Computer Interaction (HCI)** — design, evaluation, and implementation of interactive computing systems.

## Commands and Syntax

No CLI commands apply. Key **procedures and artifacts** in UX design:

1. **Research phase**: User interviews, surveys, field studies, contextual inquiry
2. **Modeling**: Create personas, workflow models, artifact models, physical models
3. **Design phase**: Sketch interaction frameworks (wireframes) → define screen layouts, flow, behavior, organization → develop visual design framework (experience attributes, visual language, style)
4. **Prototyping**: Translate wireframes from sketched storyboards → full-resolution pixel-level screens
5. **Post-launch testing cycle**:
   - Usability testing
   - A/B testing
   - Information architecture review
   - Sitemaps and user flows
   - Additional wireframing based on test results

**UX Deliverables**: wireframes, prototypes, user flow diagrams, specification docs, mockups, personas, user profiles, presentations, annotated wireframes (for developer handoff). Specification documents minimally include: title page, feature introduction, wireframes, version history.

## Relationships

- **Parent discipline**: Human Factors and Ergonomics → UX Design
- **UX Design contains**: Visual Design, Information Architecture, Interaction Design, Usability, Accessibility, HCI, User Research
- **UX Design is a component of**: Customer Experience (CX)
- **UI Design** is a narrower subset focused solely on interface appearance
- **Usability** intersects with but does not fully contain UX
- **WCAG / Accessibility** falls under usability but has its own compliance standards
- **Agile / Design Thinking**: UX design processes are increasingly aligned with agile software development methodologies
- **Technical & Professional Communication (TPC)**: UX writing is an emerging bridge between TPC and UX design
- Related disciplines: action research, activity-centered design, participatory design, process-centered design

## Exam-Relevant Points

- Don Norman coined "user experience" — wanted to go beyond "human interface" and "usability."
- UX design is **research-driven**, not opinion-driven — this distinguishes it from purely aesthetic design.
- **UX ≠ UI**: UX encompasses all aspects of perceived experience; UI focuses on the interface.
- **Usability is necessary but not sufficient** for good UX — usability is a subset.
- ISO definition of usability: effectiveness, efficiency, satisfaction by specified users for specified goals in a specified context.
- WCAG four principles: **Perceivable, Operable, Understandable, Robust (POUR)**.
- Key UX roles: UX researcher, information architect, interaction designer, human factors engineer, visual designer, UX writer.
- UX specification documents must include at minimum: title page, feature introduction, wireframes, version history.
- Personas are **composite archetypes based on behavior patterns** — not demographic profiles.
- Interaction design has evolved from specifying UI components to designing **contextual interfaces** based on user needs.
- UX testing should happen **early and often**, not just at the end.
- A/B testing is classified as a **quantitative** UX testing method.
