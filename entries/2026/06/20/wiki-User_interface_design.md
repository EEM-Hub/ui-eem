## User Interface (UI) Design: Principles, Process, and Standards

User interface design is the discipline of designing interfaces for machines and software with the goal of maximizing usability and user experience. It encompasses graphical, voice, and gesture-based interfaces, and is guided by user-centered design principles, the EDIPT design thinking framework, ISO 9241 ergonomic standards, and usability testing methodologies.

## Key Concepts

- **UI design** focuses on information architecture — clearly communicating what's important to the user and making interaction as simple and efficient as possible.
- **Three types of user interfaces**: Graphical (GUIs — visual representations on screen), Voice (e.g., Siri, Alexa), and Gesture-based (e.g., VR environments using body interaction).
- **UI vs. UX**: UI design is the craft of building the interface itself (the "look and feel"); UX design encompasses the entire process of creating the user experience, including underlying data and content quality.
- **Usability** (per ISO 9241): defined by three quality factors — **effectiveness** (achieving intended goals), **efficiency** (resources expended), and **satisfaction** (user acceptance).
- **Design aesthetics** can enhance or detract from usability — attractive interfaces tend to work better (Norman, 2002).
- **IFIP user interface reference model** structures interfaces along four dimensions: input/output (look), dialogue (feel), technical/functional (tool access), and organizational (communication support).

## Commands and Syntax

No CLI commands. The primary procedural framework is:

- **EDIPT Design Thinking Framework** (David M. Kelley, 2004 — Stanford d.school):
  1. **Empathize** — Conduct user research (semi-structured interviews) to understand needs, workflows, technical savviness, and aesthetic preferences.
  2. **Define** — Create a one-sentence problem statement: user + specific need + desired outcome.
  3. **Ideate** — Brainstorm solutions aligned with feasibility, viability, and desirability.
  4. **Prototype** — Build solutions at varying fidelity (low, mid, high); explore multiple designs.
  5. **Test** — Present prototypes to target audience; iterate based on feedback.
  - The framework is **non-linear** — designers may jump between stages and iterate repeatedly.

- **Usability evaluation methods**:
  - **Usability inspection**: cognitive walkthrough, heuristic evaluation, pluralistic walkthrough (cheaper, usable on prototypes/specs).
  - **Usability testing**: testing prototypes on actual users, often using **think-aloud protocol**.

## Relationships

- **ISO 9241** is the governing international standard, with Part 10 (dialogue principles), Part 11 (usability definition), Part 12 (information presentation), and Part 13 (user guidance).
- **Design thinking** connects UI design to broader product development methodologies.
- **Human-computer interaction (HCI)** is the parent academic discipline.
- **Related design fields**: interaction design, information architecture, experience design, web design, industrial design, software design.
- **Nielsen Norman Group** (Jakob Nielsen + Don Norman) — foundational influence on usability heuristics and UX/UI distinction.
- **Graphic design and typography** serve as supporting disciplines for usability and aesthetics.

## Exam-Relevant Points

- **Seven ISO 9241 Dialogue Principles**: suitability for the task, self-descriptiveness, controllability, conformity with user expectations, error tolerance, suitability for individualization, suitability for learning.
- **Seven Presentation Attributes** (ISO 9241 Part 12): clarity, discriminability, conciseness, consistency, detectability, legibility, comprehensibility.
- **Five means of user guidance** (ISO 9241 Part 13): prompts, feedback, status information, error management, on-line help.
- **Usability = effectiveness + efficiency + satisfaction** (ISO 9241 Part 11).
- **EDIPT** = Empathize, Define, Ideate, Prototype, Test — non-linear and iterative.
- **Jakob Nielsen's 10 Usability Heuristics** are a foundational evaluation tool (referenced but not enumerated in this source).
- **Usability inspection vs. usability testing**: inspection is cheaper and applicable to prototypes/specs; testing uses real users and think-aloud protocol.
- **UI design ≠ UX design**: UI is a subset focused on the interface; UX covers the total experience including content, data, and context.
- **Don Norman** quote: a perfect UI still yields poor UX if underlying content/data is inadequate.
