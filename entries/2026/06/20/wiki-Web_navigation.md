## Web Navigation: Types, Styles, and Design Principles

Web navigation is the process of traversing information resources on the World Wide Web, which is organized as hypertext or hypermedia. This page covers the history of web navigation since Tim Berners-Lee's 1989 invention of the Web, the classification of navigation types (hierarchical, global, local), common navigation styles (navigation bars, sitemaps, dropdown menus, flyout menus, named anchors), and the design challenges involved in creating effective navigation systems.

## Key Concepts

- **Web navigation** — the act of moving through a network of web resources using a web browser as the user interface
- **Navigation systems on a website include four pieces**: global, local, supplemental, and contextual navigation
- **Hierarchical navigation** — structured general-to-specific; the primary navigation system but considered restricting on its own
- **Global navigation** — shows top-level sections/pages; present on every page of the site
- **Local navigation** — links within the text of a page that connect to other pages within the same site
- **Information architecture** — the underlying model/concept of information that governs how navigation is organized; no universal guidelines exist because navigation varies so much between sites
- Navigation must account for differences between logged-in vs. logged-out users, shallow vs. deep multi-level architectures, and varying content structures

## Relationships

- **Web design / Usability** — navigation design is a central theme in web design, directly impacting usability
- **Human-Computer Interaction (HCI)** — web navigation is a specific case of interaction techniques between users and digital systems
- **Web browsers** — the user interface through which navigation occurs
- **Hypertext / Hypermedia** — the foundational organizational model that makes web navigation possible
- **Sitemaps and web crawlers** — sitemaps serve both users (navigation aid) and crawlers (discoverability)
- **Web traffic / Web literacy** — navigation patterns influence traffic flow; navigation skills are part of web literacy
- **Mobile devices / Smartphones** — expanded the contexts and constraints for navigation design

## Exam-Relevant Points

- Tim Berners-Lee invented the World Wide Web in **1989**, which introduced web navigation
- The **four navigational pieces** of a website: global, local, supplemental, contextual
- **Hierarchical navigation** is the primary system but is insufficient alone — additional systems are needed
- **Global navigation** appears on every page and shows top-level sections
- **Local navigation** consists of in-text links within a specific section of a site
- A **sitemap** can be both a planning document for web design and a published web page listing site pages hierarchically
- **No universal guidelines** exist for navigation design — it depends on information architecture specific to each site
- A **navigation bar** is a section of a site intended to aid visitors in traveling through the document
- **Named anchors** allow designers to anchor a URL to specific text on a page, creating clickable links
