The **accordion** is a [graphical control element](./Graphical_control_element) comprising a vertically stacked list of items, such as labels or [thumbnails](./Thumbnail). Each item can be "expanded" or "collapsed" to reveal the content associated with that item. There can be zero expanded items, exactly one, or more than one item expanded at a time, depending on the configuration.

 

The term stems from the musical [accordion](./Accordion) in which sections of the bellows can be expanded by pulling outward.

 

A common example of an accordion is the Show/Hide [operation](./Inference) of a box region, but extended to have multiple sections in a list.

 

An accordion is similar in purpose to a [tabbed interface](./Tabbed_interface), a list of items where exactly one item is expanded into a [panel](./Panel_(computer_software)) (i.e. list items are [shortcuts](./File_shortcut) to access separate panels).

 

## User definition

 

Several windows are stacked on each other. All of them are "[shaded](./WindowShade)", so only their captions are visible. If one of them is clicked, to make it active, it is "unshaded" or "maximized". Other windows in accordion are displaced around top or bottom edge.

 

## Examples

 

A common example using a GUI accordion is the Show/Hide operation of a box region, but extended to have multiple sections in a list.

 

The list view of [Google Reader](./Google_Reader) also features this.

 

In an early example, Apple's download page used roll-over accordions in 2008. In this example, captured in the [Wayback Machine](./Wayback_Machine) in the [Internet Archive](./Internet_Archive), the left column of the page includes three categories that expand on roll-over: "All Downloads", "Top Apple Downloads", and "Top Downloads".[[1]](./Accordion_(GUI)#cite_note-1)
