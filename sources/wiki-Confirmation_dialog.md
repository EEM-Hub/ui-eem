Dialog box in an computer interface 

**Confirmation dialog** (sometimes called a warning [alert box](./Alert_dialog_box))[[1]](./Confirmation_dialog#cite_note-javaHIG-1) is a [dialog box](./Dialog_box) that asks user to approve requested operation. Usually this dialog appears before a potentially dangerous operation is performed (program termination, file deletion, etc.)

 

Typically confirmation dialog boxes have two [buttons](./Button_(computing)) (e.g. *Yes* / *No*, *Confirm* / *Cancel*) or three buttons (e. g. *Save* / *Discard* / *Cancel*).

 

Some [human interface guidelines](./Human_interface_guidelines) recommend avoiding unnecessary confirmation dialogs.[[2]](./Confirmation_dialog#cite_note-2) [BlackBerry](./BlackBerry) and Sun [Java](./Java_(software_platform)) UI guidelines recommended a confirmation button be put before a cancellation button; but a default button should not be associated with a major destructive action.[[1]](./Confirmation_dialog#cite_note-javaHIG-1)[[3]](./Confirmation_dialog#cite_note-3)
