In computer [graphical user interfaces](./Graphical_user_interface), **drag and drop** is a [pointing device gesture](./Pointing_device_gesture) in which the [user](./User_(computing)) selects a virtual object by "grabbing" it and dragging it to a different location or onto another virtual object. In general, it can be used to invoke many kinds of actions, or create various types of associations between two [abstract objects](./Abstract_object).

 

As a feature, drag-and-drop support is not found in all software, though it is sometimes a fast and easy-to-learn technique. However, it is not always clear to users that an item can be dragged and dropped, or what command is performed by the drag and drop, which can decrease usability.[[1]](./Drag_and_drop#cite_note-1)

 

## Actions

 

The basic sequence involved in drag and drop is:

 
- Move the [pointer](./Pointer_(computing_WIMP)) to the object
- Press, and hold down, the button on the [mouse](./Computer_mouse) or other [pointing device](./Pointing_device), to "grab" the object
- "Drag" the object to the desired location by moving the pointer to this one
- "Drop" the object by releasing the button

 

Dragging requires more physical effort than moving the same pointing device without holding down any buttons. Because of this, a user cannot move as quickly and precisely while dragging (see [Fitts' law](./Fitts'_law)). However, drag-and-drop operations have the advantage of thoughtfully chunking together two operands (the object to drag, and the drop location) into a single action.[[2]](./Drag_and_drop#cite_note-2)
Extended dragging and dropping (as in graphic design) can stress the mousing hand.

 

A design problem appears when the same button [selects](./Selection_(user_interface)) and drags items. Imprecise movement can cause an attempt to select an object to register as a dragging motion.

 

Another problem is that the target of the dropping can be hidden under other objects. The user would have to stop the dragging, make both the source and the target visible and start again. In classic Mac OS the top-of-screen menu bar served as a universal "drag cancel" target. This issue has been dealt with in [Mac OS X](./Mac_OS_X) with the introduction of [Exposé](./Exposé_(Mac_OS_X)).

 

## In Mac OS

 

Drag and drop, called **click and drag** at the time, was used in the [original Macintosh](./Macintosh_128K) to manipulate files (for example, copying them between disks[[3]](./Drag_and_drop#cite_note-3) or folders[[4]](./Drag_and_drop#cite_note-4)). [System 7](./System_7) added the ability to open a document in an application by dropping the document icon onto the application's icon.

 

Apple added "Macintosh Drag and Drop" to [System 7.5](./System_7.5), extending "click and drag" to common clipboard operations like copying or moving textual content within a document. Content could also be dragged into the filesystem to create a "clipping file" which could then be stored and reused. Files could also be dropped on application windows, for example to enclose a document in an email, or add an image to a word processor document.

 

For most of its history, Mac OS has used a [single button mouse](./Mouse_button) with the button covering a large portion of the top surface of the mouse. This may mitigate the ergonomic concerns of keeping the button pressed while dragging.

 

## In OS/2

 

The [Workplace Shell](./Workplace_Shell) of [OS/2](./OS/2) uses dragging and dropping extensively with the [secondary mouse button](./Mouse_button), leaving the primary one for selection and clicking.
Its use like that of other advanced [Common User Access](./Common_User_Access) features distinguished native OS/2 applications from [platform-independent](./Platform-independent) ports.

 

## In web design

 

### In HTML

 

The [HTML5](./HTML5) working draft specification includes support for drag and drop.[[5]](./Drag_and_drop#cite_note-5) HTML5 supports different kinds of dragging and dropping features including:

 
- Drag and Drop texts and HTML codes
- Drag and Drop HTML elements
- Drag and Drop files

 

Based on needed action, one of the above types can be used. Note that when an HTML element is dragged for moving its current position, its ID is sent to the destination parent element; so it sends a text and can be considered as the first group.

 

Google's web-based e-mail application [Gmail](./Gmail) supports drag-and-drop of images and attachments in the latest [Google Chrome](./Google_Chrome) browser and Apple's [Safari](./Safari_(web_browser)) (5.x). Google Images permits users to drag and drop image files into a browser to perform a [reverse image search](./Reverse_image_search).

 

### In website builders

 

A drag and drop [website builder](./Website_builder) (also called [DIY](./Do_it_yourself) website builders) offers a visual interface where users can create and customize their websites by simply "dragging" and "dropping" various elements onto a page without the need for [development](./Web_development) experience or knowledge of [coding languages](./Programming_language). [No-code platforms](./No-code_development_platform) have progressed well beyond the capabilities of early visual editors.[[6]](./Drag_and_drop#cite_note-6) With the advent of [Artificial intelligence (AI)](./Artificial_intelligence), building a website has become even quicker.[[7]](./Drag_and_drop#cite_note-7)

 

As of May 2025, more than 21 million websites were constructed with usage of drag and drop website builder. Wix accounted for roughly one-third of websites built with drag-and-drop website builders.[[8]](./Drag_and_drop#cite_note-builtwith-8) Others, such as [Weebly](./Weebly), [Hostinger](./Hostinger), and [GoDaddy](./GoDaddy), are also active in the market.[[9]](./Drag_and_drop#cite_note-9)[[8]](./Drag_and_drop#cite_note-builtwith-8) The market leaders are:[[8]](./Drag_and_drop#cite_note-builtwith-8)

## On a touch screen

 

Touch screen interfaces also include drag and drop, or more precisely, long press, and then drag, e.g. on the [iPhone](./IPhone) or [Android](./Android_(operating_system)) home screens.

 

[iOS 11](./IOS_11) implements a drag-and-drop feature which allows the user to touch items (and tap with other fingers to drag more) within an app or between apps on [iPads](./IPad).[[10]](./Drag_and_drop#cite_note-10) On iPhones, the functionality is only available within the same app that the user started the drag.[[11]](./Drag_and_drop#cite_note-11)

 

## In end-user programming

 See also: [Visual programming language](./Visual_programming_language) 

Drag and drop is considered an important program construction approach in many [end-user development](./End-user_development) systems. In contrast to more traditional, text-based programming languages, many end-user programming languages are based on visual components such as tiles or icons that are manipulated by end users through drag-and-drop interfaces. [AgentSheets](./AgentSheets),[[12]](./Drag_and_drop#cite_note-12) a programming environment for kids, introduced the modern notion of drag and drop blocks programming providing 4 core affordances: 1) Blocks that are end-user composable, 2) blocks are end-user editable, 3) blocks can be nested to represent tree structures, 4) blocks are arranged geometrically to define syntax. Drag and drop is also featured in many shader editing programs for graphics tools, such as [Blender](./Blender_(software)).[[13]](./Drag_and_drop#cite_note-13) Drag and drop also features in some video game engines, including [Unreal Engine](./Unreal_Engine), [GameMaker Studio](./GameMaker_Studio), [Construct 2](./Construct_2) and, with expansion, [Unity](./Unity_(game_engine)).

 

## Examples

 

A common example is dragging an icon on a virtual [desktop](./Desktop_environment) to a special trashcan [icon](./Icon_(computing)) to delete a file.

 

Further examples include:

 
- Dragging a data file onto a [program](./Computer_program) [icon](./Icon_(computing)) or window for viewing or processing. For instance, dropping an icon that represents a text file into a Microsoft Word window signifies "Open this document as a new document in Word"
- Moving or copying files to a new location/directory/folder,
- Adding objects to a list of objects to be processed,
- Rearranging [widgets](./Widget_(computing)) in a [graphical user interface](./Graphical_user_interface) to customize their layout,
- Dragging an attribute onto an object to which the command is to be applied,

- e.g. dragging a color onto a graphical object to change its color,

- Dragging a tool to a canvas location to apply the tool at that location,
- Creating a [hyperlink](./Hyperlink) from one location or word to another location or document.
- Most word processors allow dragging selected text from one point to another.
- Dragging a series of code blocks such as in [Blender](./Blender_(software)) for designing shaders and materials.
- Simulate a [camera panning](./Panning_(camera)) movement in image visualization and image editing software.
