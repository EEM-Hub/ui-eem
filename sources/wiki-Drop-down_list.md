A **drop-down list** (**DDL**), **drop-down menu** or just **drop-down**[[1]](./Drop-down_list#cite_note-1)
– also known as a **drop menu**, **pull-down list**, **picklist** – is a [graphical control element](./Widget_(GUI)), similar to a [list box](./List_box), that allows the user to choose one value from a list either by clicking or hovering over the menu. When a drop-down list is inactive, it displays a single value. When activated, it displays (drops down) a list of values, from which the user may select one. When the user selects a new value, the control reverts to its inactive state, displaying the selected value. It is often used in the design of graphical user interfaces, including [web design](./Web_design).

 

## Terminology

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/c/cc/Dewiki-suggesting-searchplugin.png/250px-Dewiki-suggesting-searchplugin.png)](./File:Dewiki-suggesting-searchplugin.png)A drop-down list of [search suggestions](./Search_suggestions) 

This type of control is called a "pop-up menu" on the [Macintosh](./Apple_Macintosh) platform;[[2]](./Drop-down_list#cite_note-2) however, the term "pop-up menu" is used to refer to [context menus](./Context_menu) in other GUI systems. The Macintosh also has the notion of "pull-down menus". The distinction is that, when the menu is closed, a pop-up menu's title shows the last-selected item while a pull-down menu shows a static title like a menu in the menu bar. Thus, the uses are different—pop-up menus are used to select a single option from a list while pull-down menus are used to issue commands or in cases where multiple options can be selected.

 

## HTML

 

In [web forms](./Form_(web)), the [HTML elements](./HTML_element) `<select>` and `<option>` are used to display a drop-down menu:[[3]](./Drop-down_list#cite_note-3)

 
```
<select>
  <option>option1</option>
  <option>option2</option>
  <option>option3</option>
</select>

```
