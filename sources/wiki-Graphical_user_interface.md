[![](//upload.wikimedia.org/wikipedia/commons/thumb/7/77/Example_of_a_GUI.png/250px-Example_of_a_GUI.png)](./File:Example_of_a_GUI.png)A graphical user interface (GUI) showing various elements: radio buttons, checkboxes, and other elements. A **graphical user interface**, or **GUI**[[a]](./Graphical_user_interface#cite_note-4), is a form of [user interface](./User_interface) that allows [users](./User_(computing)) to [interact with electronic devices](./Human–computer_interaction) through [graphical](./Graphics) [icons](./Icon_(computing)) and visual indicators such as [secondary notation](./Secondary_notation). In many applications, GUIs are used instead of [text-based UIs](./Text-based_user_interface), which are based on typed command labels or text navigation. GUIs were introduced in reaction to the perceived steep [learning curve](./Learning_curve) of [command-line interfaces](./Command-line_interface) (CLIs),[[4]](./Graphical_user_interface#cite_note-computerhope.com-5)[[5]](./Graphical_user_interface#cite_note-6)[[6]](./Graphical_user_interface#cite_note-7) which require commands to be typed on a [computer keyboard](./Computer_keyboard).

 

The actions in a GUI are usually performed through [direct manipulation](./Direct_manipulation_interface) of the graphical elements.[[7]](./Graphical_user_interface#cite_note-8)[[8]](./Graphical_user_interface#cite_note-9)[[9]](./Graphical_user_interface#cite_note-10) Beyond computers, GUIs are used in many handheld [mobile devices](./Mobile_device) such as [MP3](./MP3) players, portable media players, gaming devices, [smartphones](./Smartphone) and smaller household, office and [industrial controls](./Distributed_control_system). The term *GUI* tends not to be applied to other lower-[display resolution](./Display_resolution) [types of interfaces](./User_interface#Types), such as [video games](./Video_game) (where [head-up displays](./Heads-up_display_(video_games)) (*HUDs*)[[10]](./Graphical_user_interface#cite_note-11) are preferred), or not including flat screens like [volumetric displays](./Volumetric_display)[[11]](./Graphical_user_interface#cite_note-12) because the term is restricted to the scope of [2D](./Two-dimensional_Euclidean_space) display screens able to describe generic information, in the tradition of the [computer science](./Computer_science) research at the [Xerox Palo Alto Research Center](./PARC_(company)).

 

## GUI and interaction design

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/a/a1/Linux_kernel_INPUT_OUPUT_evdev_gem_USB_framebuffer.svg/250px-Linux_kernel_INPUT_OUPUT_evdev_gem_USB_framebuffer.svg.png)](./File:Linux_kernel_INPUT_OUPUT_evdev_gem_USB_framebuffer.svg)The GUI is presented (displayed) on the computer screen. It is the result of processed user input and usually the main interface for human-machine interaction. The [touch UIs](./Touch_user_interface) popular on small mobile devices are an overlay of the visual output to the visual input. 

Designing the visual composition and temporal behavior of a GUI is an important part of [software application](./Software_application) programming in the area of [human–computer interaction](./Human–computer_interaction). Its goal is to enhance the efficiency and ease of use for the underlying logical design of a stored [program](./Computer_program), a design discipline named *[usability](./Usability)*. Methods of user-centered design are used to ensure that the visual language introduced in the design is well-tailored to the tasks.

 

The visible graphical interface features of an application are sometimes referred to as *chrome* or *GUI*.[[12]](./Graphical_user_interface#cite_note-13)[[13]](./Graphical_user_interface#cite_note-14)[[14]](./Graphical_user_interface#cite_note-15) Typically, users interact with information by manipulating visual [widgets](./Widget_(GUI)) that allow for interactions appropriate to the kind of data they hold. The widgets of a well-designed interface are selected to support the actions necessary to achieve the goals of users. A [model–view–controller](./Model–view–controller) allows flexible structures in which the interface is independent of and indirectly linked to application functions, so the GUI can be customized easily. This allows users to select or design a different *skin* or *[theme](./Theme_(computing))* at will, and eases the designer's work to change the interface as user needs evolve. Good GUI design relates to users more, and to system architecture less.
Large widgets, such as [windows](./Window_(computing)), usually provide a frame or container for the main presentation content such as a web page, email message, or drawing. Smaller ones usually act as a user-input tool.

 

A GUI may be designed for the requirements of a [vertical market](./Vertical_market) as application-specific GUIs. Examples include [automated teller machines](./Automated_teller_machine) (ATM), [point of sale](./Point_of_sale) (POS) touchscreens at restaurants,[[15]](./Graphical_user_interface#cite_note-16) [self-service checkouts](./Self-checkout) used in a retail store, airline self-ticket and check-in, information kiosks in a public space, like a train station or a museum, and monitors or control screens in an embedded industrial application which employ a [real-time operating system](./Real-time_operating_system) (RTOS).

 

[Cell phones](./Mobile_phone) and handheld game systems also employ application specific touchscreen GUIs. Newer automobiles use GUIs in their navigation systems and multimedia centers, or navigation multimedia center combinations.

## Components

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/9/95/Schema_of_the_layers_of_the_graphical_user_interface.svg/250px-Schema_of_the_layers_of_the_graphical_user_interface.svg.png)](./File:Schema_of_the_layers_of_the_graphical_user_interface.svg)Layers of a GUI based on a [windowing system](./Windowing_system) Main article: [List of graphical user interface elements](./List_of_graphical_user_interface_elements) Further information: [WIMP (computing)](./WIMP_(computing)), [Window manager](./Window_manager), and [Desktop environment](./Desktop_environment) 

A GUI uses a combination of technologies and devices to provide a platform that users can interact with, for the tasks of gathering and producing information.

 

A series of elements conforming a [visual language](./Visual_language) have evolved to represent information stored in computers. This makes it easier for people with few computer skills to work with and use computer software. The most common combination of such elements in GUIs is the *windows, icons, text fields, canvases, menus, pointer* ([WIMP](./WIMP_(computing))) paradigm, especially in [personal computers](./Personal_computer).[[16]](./Graphical_user_interface#cite_note-17)

 

The WIMP style of interaction uses a virtual [input device](./Input_device) to represent the position of a [pointing device's interface](./Pointing_device), most often a [mouse](./Computer_mouse), and presents [information](./Information) organized in windows and represented with [icons](./Icon_(computing)). Available commands are compiled together in menus, and actions are performed making gestures with the pointing device. A [window manager](./Window_manager) facilitates the interactions between windows, [applications](./Application_software), and the [windowing system](./Windowing_system). The windowing system handles hardware devices such as pointing devices, graphics hardware, and positioning of the pointer.

 

In [personal computers](./Personal_computer), all these elements are modeled through a [desktop metaphor](./Desktop_metaphor) to produce a simulation called a [desktop environment](./Desktop_environment) in which the display represents a desktop, on which documents and folders of documents can be placed. Window managers and other software combine to simulate the desktop environment with varying degrees of realism.

 

Entries may appear in a list to make space for text and details, or in a grid for compactness and larger icons with little space underneath for text. Variations in between exist, such as a list with multiple columns of items and a grid of items with rows of text extending sideways from the icon.[[17]](./Graphical_user_interface#cite_note-18)

 

Multi-row and multi-column layouts commonly found on the web are "shelf" and "waterfall". The former is found on [image search engines](./Image_search_engine), where images appear with a fixed height but variable length, and is typically implemented with the CSS property and parameter `display: inline-block;`. A waterfall layout found on [Imgur](./Imgur) and [TweetDeck](./TweetDeck) with fixed width but variable height per item is usually implemented by specifying `column-width:`.

 

## Post-WIMP interface

 Main article: [Post-WIMP](./Post-WIMP) 

Smaller app mobile devices such as [personal digital assistants](./Personal_digital_assistant) (PDAs) and [smartphones](./Smartphone) typically use the WIMP elements with different unifying metaphors, due to constraints in space and available input devices. Applications for which WIMP is not well suited may use newer [interaction techniques](./Interaction_technique), collectively termed *[post-WIMP](./Post-WIMP)* UIs.[[18]](./Graphical_user_interface#cite_note-19)

 

As of 2011, some touchscreen-based operating systems such as Apple's [iOS](./IOS) ([iPhone](./IPhone)) and [Android](./Android_(operating_system)) use the class of GUIs named post-WIMP. These support styles of interaction using more than one finger in contact with a display, which allows actions such as pinching and rotating, which are unsupported by one pointer and mouse.[[19]](./Graphical_user_interface#cite_note-20)

 

## Interaction

 

[Human interface devices](./Human_interface_device), for the efficient interaction with a GUI include a [computer keyboard](./Computer_keyboard), especially used together with [keyboard shortcuts](./Keyboard_shortcut), [pointing devices](./Pointing_device) for the [cursor](./Cursor_(user_interface)) (or rather [pointer](./Pointer_(user_interface))) control: [mouse](./Mouse_(computing)), [pointing stick](./Pointing_stick), [touchpad](./Touchpad), [trackball](./Trackball), [joystick](./Joystick), [virtual keyboards](./Virtual_keyboard), and [head-up displays](./Head-up_display) (translucent information devices at the eye level).

 

There are also actions performed by programs that affect the GUI. For example, there are components like [inotify](./Inotify) or [D-Bus](./D-Bus) to facilitate communication between computer programs.

 

## History

 Main article: [History of the graphical user interface](./History_of_the_graphical_user_interface) 

### Early efforts

 

[Ivan Sutherland](./Ivan_Sutherland) developed [Sketchpad](./Sketchpad) in 1963, widely held as the first graphical [computer-aided design](./Computer-aided_design) program. It used a [light pen](./Light_pen) to create and manipulate objects in engineering drawings in realtime with coordinated graphics. In the late 1960s, researchers at the [Stanford Research Institute](./SRI_International), led by [Douglas Engelbart](./Douglas_Engelbart), developed the [On-Line System](./NLS_(computer_system)) (NLS), which used text-based [hyperlinks](./Hyperlink) manipulated with a then-new device: the [mouse](./Computer_mouse). (A 1968 demonstration of NLS became known as "[The Mother of All Demos](./The_Mother_of_All_Demos)".)  In the 1970s, Engelbart's ideas were further refined and extended to graphics by researchers at [Xerox PARC](./Xerox_PARC) and specifically [Alan Kay](./Alan_Kay), who went beyond text-based hyperlinks and used a GUI as the main interface for the [Smalltalk programming language](./Smalltalk), which ran on the [Xerox Alto](./Xerox_Alto) [computer](./Computer), released in 1973. Most modern general-purpose GUIs are derived from this system.

 

The Xerox PARC GUI consisted of graphical elements such as [windows](./Window_(computing)), [menus](./Menu_(computing)), [radio buttons](./Radio_button), and [check boxes](./Check_box). The concept of [icons](./Icon_(computing)) was later introduced by [David Canfield Smith](./David_Canfield_Smith), who had written a thesis on the subject under the guidance of Kay.[[20]](./Graphical_user_interface#cite_note-MIT-21)[[21]](./Graphical_user_interface#cite_note-Nader-22)[[22]](./Graphical_user_interface#cite_note-Pygmalion-23) The PARC GUI employs a [pointing device](./Pointing_device) along with a keyboard. These aspects can be emphasized by using the alternative term and acronym for *windows, icons, menus, [pointing device](./Pointing_device)* ([WIMP](./WIMP_(computing))). This effort culminated in the 1973 [Xerox Alto](./Xerox_Alto), the first computer with a GUI, though the system never reached commercial production.

 

The first commercially available computer with a GUI was the 1979 [PERQ workstation](./PERQ), manufactured by Three Rivers Computer Corporation. Its design was heavily influenced by the work at Xerox PARC. In 1981, Xerox eventually commercialized the ideas from the Alto in the form of a new and enhanced system – the Xerox 8010 Information System – more commonly known as the [Xerox Star](./Xerox_Star).[[23]](./Graphical_user_interface#cite_note-24)[[24]](./Graphical_user_interface#cite_note-25) These early systems spurred many other GUI efforts, including [Lisp machines](./Lisp_machine) by [Symbolics](./Symbolics) and other manufacturers, the [Apple Lisa](./Apple_Lisa) (which presented the concept of [menu bar](./Menu_bar) and [window controls](./Window_manager)) in 1983, the [Apple](./Apple_Computer) [Macintosh 128K](./Macintosh_128K) in 1984, and the [Atari ST](./Atari_ST) with [Digital Research](./Digital_Research)'s [GEM](./Graphics_Environment_Manager), and Commodore [Amiga](./Amiga) in 1985. [Visi On](./Visi_On) was released in 1983 for the [IBM PC compatible](./IBM_PC_compatible) computers, but was never popular due to its high hardware demands.[[25]](./Graphical_user_interface#cite_note-26) Nevertheless, it was a crucial influence on the contemporary development of [Microsoft Windows](./Microsoft_Windows).[[26]](./Graphical_user_interface#cite_note-27)

 

Apple, Digital Research, IBM and Microsoft used many of Xerox's ideas to develop products, and IBM's [Common User Access](./IBM_Common_User_Access) specifications formed the basis of the GUIs used in Microsoft Windows, IBM [OS/2](./OS/2) [Presentation Manager](./Presentation_Manager), and the Unix [Motif](./Motif_(software)) toolkit and [window manager](./Window_manager). These ideas evolved to create the interface found in current versions of Microsoft Windows, and in various [desktop environments](./Desktop_environment) for [Unix-like](./Unix-like) [operating systems](./Operating_system), such as macOS and [Linux](./Linux). Thus most current GUIs have largely common idioms.

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/2/2f/Apple_Lisa_Computer.jpg/250px-Apple_Lisa_Computer.jpg)](./File:Apple_Lisa_Computer.jpg)An Apple Lisa (1983) demonstrating the Lisa Office System (LisaOS), which featured Apple Computer's first commercially available GUI 

### Popularization

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/6/65/Hewlett_Packard_200LX.jpg/250px-Hewlett_Packard_200LX.jpg)](./File:Hewlett_Packard_200LX.jpg)[HP LX System Manager](./System_Manager_(HP_LX)) running on a [HP 200LX](./HP_200LX) 

The early 1980s saw growing interest in GUIs. The [Apple Lisa](./Apple_Lisa) was released in 1983, but was expensive and commercially unsuccessful. Individual applications for many platforms presented their own GUI variants.[[27]](./Graphical_user_interface#cite_note-28) Despite the GUI's advantages, many reviewers questioned the value of the entire concept,[[28]](./Graphical_user_interface#cite_note-29) citing hardware limits and problems in finding compatible software.

 

In 1984, Apple introduced the Macintosh via [the "1984" television commercial](./1984_(advertisement)) during [Super Bowl XVIII](./Super_Bowl_XVIII),[[29]](./Graphical_user_interface#cite_note-30) with [allusions](./Allusion) to [George Orwell](./George_Orwell)'s novel *[Nineteen Eighty-Four](./Nineteen_Eighty-Four)*. The goal of the commercial was to make people think about computers, identifying the user-friendly interface as a personal computer which departed from prior business-oriented systems,[[30]](./Graphical_user_interface#cite_note-friedman-31) and becoming a signature representation of Apple products.[[31]](./Graphical_user_interface#cite_note-32)

 

The 1985 [Atari ST](./Atari_ST) shipped with the [GEM](./Graphics_Environment_Manager) GUI from [Digital Research](./Digital_Research), which was also published for [MS-DOS](./MS-DOS).
The [Amiga 1000](./Amiga_1000) was released the same year, though not widely available until 1986, with the [Workbench](./Workbench_(AmigaOS)#Workbench_1.x) graphical desktop. This interface ran as a separate task, meaning it was very responsive and, unlike other GUIs of the time, it did not freeze up when a program was busy.

 

[Windows 95](./Windows_95), accompanied by an extensive marketing campaign,[[32]](./Graphical_user_interface#cite_note-WinHype-33) was a major success in the marketplace at launch and shortly became the most popular desktop operating system.[[33]](./Graphical_user_interface#cite_note-34)

 

In 2007, with the [iPhone](./IPhone)[[34]](./Graphical_user_interface#cite_note-35) and later in 2010 with the introduction of the [iPad](./IPad),[[35]](./Graphical_user_interface#cite_note-36)  Apple popularized the post-WIMP style of interaction for [multi-touch](./Multi-touch) screens, and those devices were considered to be milestones in the development of [mobile devices](./Mobile_device).[[36]](./Graphical_user_interface#cite_note-BallStillDoesnt2010-37)[[37]](./Graphical_user_interface#cite_note-infoworld-38)

 

The GUIs familiar to most people as of the mid-late 2010s are [ Windows](./Windows), [macOS](./MacOS), and the [X Window System](./X_Window_System) interfaces for desktop and laptop computers, and [Android](./Android_(operating_system)), Apple's [iOS](./IOS), [Symbian](./Symbian), [BlackBerry OS](./BlackBerry_OS), [Windows Phone](./Windows_Phone)/[Windows 10 Mobile](./Windows_10_Mobile), [Tizen](./Tizen), [WebOS](./WebOS), and [Firefox OS](./Firefox_OS) for handheld ([smartphone](./Smartphone)) devices.[[38]](./Graphical_user_interface#cite_note-39)[[39]](./Graphical_user_interface#cite_note-40)

And you don't see that on a PC. The PC is very much of a conceptual machine; you move information around the way you move formulas, elements on either side of an equation. ### Command-line interfaces

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/e/e7/Bash_screenshot.png/250px-Bash_screenshot.png)](./File:Bash_screenshot.png)A modern Command-Line Interface (CLI) 

Since the commands available in command line interfaces can be many, complex operations can be performed using a short sequence of words and symbols. Custom functions may be used to facilitate access to frequent actions. 
Command-line interfaces are more [lightweight](./Minimalism_(computing)), as they only recall information necessary for a task; for example, no preview thumbnails or graphical rendering of web pages. This allows greater efficiency and productivity once many commands are learned.[[4]](./Graphical_user_interface#cite_note-computerhope.com-5)  But reaching this level takes some time because the command words may not be easily discoverable or [mnemonic](./Mnemonic). Also, using the command line can become slow and error-prone when users must enter long commands comprising many parameters or several different filenames at once. However, *windows, icons, menus, pointer* ([WIMP](./WIMP_(computing))) interfaces present users with many [widgets](./Widget_(GUI)) that represent and can trigger some of the system's available commands.

 

GUIs can be made quite hard when dialogs are buried deep in a system or moved about to different places during redesigns. Also, icons and dialog boxes are usually harder for users to script.

 

WIMPs extensively use [modes](./Mode_(user_interface)), as the meaning of all keys and clicks on specific positions on the screen are redefined all the time. Command-line interfaces use modes only in limited forms, such as for current directory and [environment variables](./Environment_variable).

 

Most modern [operating systems](./Operating_system) provide both a GUI and some level of a CLI, although the GUIs usually receive more attention.

 

### GUI wrappers

 

GUI wrappers find a way around the [command-line interface](./Command-line_interface) versions (CLI) of (typically) [Linux](./Linux) and [Unix-like](./Unix-like) software applications and their [text-based UIs](./Text-based_user_interface) or typed command labels. While command-line or text-based applications allow users to run a program non-interactively, GUI wrappers atop them avoid the steep [learning curve](./Learning_curve) of the command-line, which requires commands to be typed on the [keyboard](./Computer_keyboard). By starting a GUI wrapper, [users](./User_(computing)) can intuitively [interact](./Human–computer_interaction) with, start, stop, and change its working parameters, through graphical [icons](./Icon_(computing)) and visual indicators of a [desktop environment](./Desktop_environment), for example. Applications may also provide both interfaces, and when they do the GUI is usually a WIMP wrapper around the command-line version. This is especially common with applications designed for [Unix-like](./Unix-like) operating systems. The latter used to be implemented first because it allowed the developers to focus exclusively on their product's functionality without bothering about interface details such as designing icons and placing buttons. Designing programs this way also allows users to run the program in a [shell script](./Shell_script).

 

## Three-dimensional graphical user interface

 This section is about uniquely software 3D UIs. For both software and hardware 3D input/output devices, see [3D UIs](./3D_UIs). 

Many environments and games use the methods of [3D graphics](./3D_graphics) to project 3D GUI objects onto the screen. The use of 3D graphics has become increasingly common in mainstream operating systems (ex. [Windows Aero](./Windows_Aero), and [Aqua](./Aqua_(user_interface)) (macOS)) to create attractive interfaces, termed eye candy (which includes, for example, the use of [drop shadows](./Drop_shadow) underneath windows and the [cursor](./Cursor_(user_interface))), or for functional purposes only possible using three dimensions. For example, user switching is represented by rotating a cube with faces representing each user's workspace, and window management is represented via a [Rolodex](./Rolodex)-style flipping mechanism in [Windows Vista](./Windows_Vista) (see [Windows Flip 3D](./Windows_Flip_3D)). In both cases, the operating system transforms windows on-the-fly while continuing to update the content of those windows.

 

The GUI is usually WIMP-based, although occasionally other metaphors surface, such as those used in [Microsoft Bob](./Microsoft_Bob), 3dwm, File System Navigator, [File System Visualizer](./File_System_Visualizer), 3D Mailbox,[[41]](./Graphical_user_interface#cite_note-42)[[42]](./Graphical_user_interface#cite_note-43) and [GopherVR](./GopherVR). [Zooming](./Zooming_user_interface) (ZUI) is a related technology that promises to deliver the representation benefits of 3D environments without their usability drawbacks of orientation problems and hidden objects. In 2006, [Hillcrest Labs](./Hillcrest_Labs) introduced the first ZUI for television.[[43]](./Graphical_user_interface#cite_note-Moren-44) Other innovations include the menus on the [PlayStation 2](./PlayStation_2); the menus on the [Xbox](./Xbox_(console)); Sun's [Project Looking Glass](./Project_Looking_Glass); [Metisse](./Metisse), which was similar to Project Looking Glass;[[44]](./Graphical_user_interface#cite_note-45) [BumpTop](./BumpTop), where users can manipulate documents and windows with realistic movement and physics as if they were physical documents; [Croquet OS](./Croquet_OS), which is built for collaboration;[[45]](./Graphical_user_interface#cite_note-46) and [compositing window managers](./Compositing_window_manager) such as [Enlightenment](./Enlightenment_(software)) and [Compiz](./Compiz). [Augmented reality](./Augmented_reality) and [virtual reality](./Virtual_reality) also make use of 3D GUI elements.[[46]](./Graphical_user_interface#cite_note-47)

 

### In science fiction

 

3D GUIs have appeared in [science fiction](./Science_fiction) literature and [films](./Science_fiction_film), even before certain technologies were feasible or in common use.[[47]](./Graphical_user_interface#cite_note-48)

 
- In prose fiction, 3D GUIs have been portrayed as immersible environments, [coined](./Coined_term) as [William Gibson](./William_Gibson)'s "[cyberspace](./Cyberspace)" and [Neal Stephenson](./Neal_Stephenson)'s "[metaverse](./Metaverse)" and "[avatars](./Avatar_(computing))".
- The 1993 American film *[Jurassic Park](./Jurassic_Park_(film))* features [Silicon Graphics](./Silicon_Graphics)' 3D file manager File System Navigator, a real-life file manager for [Unix](./Unix) operating systems.
- The film [*Minority Report*](./Minority_Report_(film)) has scenes of police officers using specialized 3D data systems.
