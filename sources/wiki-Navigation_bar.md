User interface element to aid navigation 

A **navigation bar** (or **navigation system**) is a section of a [graphical user interface](./Graphical_user_interface) intended to aid visitors in accessing information. Navigation bars are implemented in [operating systems](./Operating_systems), [file browsers](./File_browser),[[1]](./Navigation_bar#cite_note-1) [web browsers](./Web_browser), apps, web sites and other similar [user interfaces](./User_interface).

 

## File browsers

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/f/f5/Thunar-1.6.2.png/250px-Thunar-1.6.2.png)](./File:Thunar-1.6.2.png)[Thunar](./Thunar)'s navigation bar 

File browsers use a navigation bar to assist the user in traversing the [filesystem](./Filesystem). Navigation bars may include the current [path](./Path_(computing)), [breadcrumbs](./Breadcrumb_(navigation)), or a list of [favorites](./Favorites).[[2]](./Navigation_bar#cite_note-2)

 

## Web browsers

 

A web browser navigation bar includes the back and forward buttons, as well as the [Location bar](./Location_bar) where [URLs](./URL) are entered.[[3]](./Navigation_bar#cite_note-3) Formerly, the functionality of the navigation bar was split between the browser's [toolbar](./Toolbar) and the [address bar](./Address_bar), but [Google Chrome](./Google_Chrome) introduced the practice of merging the two. 

 

## Web design

 

Typically, websites will have a primary navigation bar[[4]](./Navigation_bar#cite_note-4) and sometimes secondary navigation bar on all pages. These webpage sections will include links to the most important sections of the site. The [implementation](./Implementation) and design of navigation bars is a crucial aspect of [web design](./Web_design) and web [usability](./Usability).

 

In general, navigation bars are found in a page's [header](./Page_header) but may also be found in the form of a sidebar.

- [![A minimally styled header bar](//upload.wikimedia.org/wikipedia/commons/thumb/b/b0/Wikipedia_CamelCase_Navigation_Bar.png/250px-Wikipedia_CamelCase_Navigation_Bar.png)](./File:Wikipedia_CamelCase_Navigation_Bar.png)A minimally styled header bar

With different purposes, there are different kinds of the navigation bars to be chosen, such as horizontal navigation bars and vertical navigation bars. And with a dynamic website project including JavaScript, navigation bars can be designed to be responsive.

 

### HTML5 nav tag

 

Some early versions of [Netscape](./Netscape) used the [HTML](./HTML) link tag to construct a navigation bar to navigate websites.[[5]](./Navigation_bar#cite_note-5) Today, the nav tag can be used for the same purpose.[[6]](./Navigation_bar#cite_note-6)  In [HTML5](./HTML5), navigation elements are enclosed in a `<nav>` tag, often, containing a list of links.

 
```
<nav>
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/blog">Blog</a></li>
    <li><a href="/contact">Contact</a></li>
    <li><a href="/about">About</a></li>
  </ul>
</nav>

```
