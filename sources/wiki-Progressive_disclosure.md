Concept in interaction design Not to be confused with [Responsible disclosure](./Responsible_disclosure). 

**Progressive disclosure** is an [interaction design](./Interaction_design) pattern used to make applications easier to learn and less error-prone. It does so by deferring some advanced or rarely-used features to a secondary screen[[1]](./Progressive_disclosure#cite_note-1) and designing workflows where information is revealed when it becomes relevant to the current task.[[2]](./Progressive_disclosure#cite_note-2)

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/7/7d/Expander.png/250px-Expander.png)](./File:Expander.png)Disclosure widget ("Browse for...") in the [GTK+](./GTK+) [file dialog](./File_dialog). 

A classic example of this pattern is the print dialog in [macOS](./MacOS). While printing a page, the print dialog shows only a small subset of choices. If the user wants more advanced options, they can click the "Show Details" button to reveal these features in a secondary screen.[*[citation needed](./Wikipedia:Citation_needed)*]

 

In the physical world, progressive disclosure is used by modern theme park designers. Long waiting lines for rides can scare away visitors, so only a small segment of the line is made visible from any vantage point. As people move ahead in line, they only get to see discrete portions of the entire line. This design can make waiting more bearable for those in line.[[3]](./Progressive_disclosure#cite_note-3)

 

## History

 

[Kristina Hooper Woolsey](./Kristina_Hooper_Woolsey), a founding member of the [Apple Human Interface Group](./Apple_Human_Interface_Group?action=edit&redlink=1), wrote in 1985 what could be considered as the seminal idea for selectively disclosing to new users how a system works:

*"In the design of interfaces one must also consider carefully how one selectively informs a user about a particular system, providing well-chosen bits and pieces that can constitute a general understanding of a system."*[[4]](./Progressive_disclosure#cite_note-4)
