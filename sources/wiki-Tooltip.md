 [![](//upload.wikimedia.org/wikipedia/commons/thumb/5/51/HTML_tooltip.png/500px-HTML_tooltip.png)](./File:HTML_tooltip.png)A web browser tooltip displayed for hyperlink to [HTML](./HTML), showing what the abbreviation stands for. 

The **tooltip** (also known as **infotip**, **hint**, [mouseover](./Mouseover) or **hover text**[[1]](./Tooltip#cite_note-1)) is a common [graphical user interface](./Graphical_user_interface) (GUI) element in which, when [hovering](./Hoverbox) over a screen element or component, a text box displays information about that element, such as a description of a button's function, what an abbreviation stands for, or the exact absolute [time stamp](./Time_stamp) over a relative time ("… ago"). In common practice, the tooltip is displayed continuously as long as the user hovers over the element or the text box provided by the tool.[[2]](./Tooltip#cite_note-:0-2) It is sometimes possible for the mouse to hover within the text box provided to activate a nested tooltip, and this can continue to any depth, often with multiple text boxes overlapped.

 this is common on Wikipedia if you activate the right setting  

On desktop, it is used in conjunction with a [cursor](./Cursor_(user_interface)), usually a [pointer](./Pointer_(user_interface)), whereby the tooltip appears when a user [hovers the pointer](./Mouseover) over an item without clicking it.[[3]](./Tooltip#cite_note-3)[[4]](./Tooltip#cite_note-4)

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/b/b2/Mobile_URL_tooltip.png/250px-Mobile_URL_tooltip.png)](./File:Mobile_URL_tooltip.png)URL tooltip in *Kiwi Browser*, a [Chromium](./Chromium_(web_browser)) derivative, revealed with the stylus on a [Samsung Galaxy Note 4](./Samsung_Galaxy_Note_4). 

On touch-screen devices, a tooltip is displayed upon long-pressing—i.e., tapping and holding—an element.[[2]](./Tooltip#cite_note-:0-2) Some smartphones have [alternative input methods](./Smartphones#Alternative_input_methods) such as a [stylus](./Stylus_(computing)), which can show tooltips when hovering above the screen.

 

A common variant of tooltips, especially in older software, is displaying a description of the tool in a [status bar](./Status_bar).[[5]](./Tooltip#cite_note-5) [Microsoft](./Microsoft)'s tooltips feature found in its [end-user](./End_user) documentation is named **ScreenTips**.[[6]](./Tooltip#cite_note-6) [Apple's](./Apple_Inc.) tooltips feature found in its [developer](./Developer_(software)) documentation is named **help tags**.[[7]](./Tooltip#cite_note-7) The [Classic Mac OS](./Classic_Mac_OS) uses a tooltips feature, though in a slightly different way, known as [balloon help](./Balloon_help).[[8]](./Tooltip#cite_note-8) Some software and applications, such as [GIMP](./GIMP), provide an option for users to turn off some or all tooltips. However, such options are left to the discretion of the developer, and are often not implemented.[[9]](./Tooltip#cite_note-9)

 

## Origin

 

The term *tooltip* originally came from older Microsoft applications (e.g. [Microsoft Word 95](./Microsoft_Word)).[[10]](./Tooltip#cite_note-10)[[11]](./Tooltip#cite_note-11) These applications would have [toolbars](./Toolbar) wherein, when moving the mouse over the Toolbar icons, displayed a short description of the function of the tool in the toolbar. More recently, these tooltips are used in various parts of an interface, not only on toolbars. The concept of tooltips as contextual help elements in user interfaces emerged with early graphical user interfaces to enhance usability.[[12]](./Tooltip#cite_note-12)

 

## Examples

 

[CSS](./CSS), [HTML](./HTML), [JavaScript](./JavaScript), and other coding systems allow web designers to create customized tooltips.[[13]](./Tooltip#cite_note-:1-13)

 

Demonstrations of tooltip usage are prevalent on web pages. Many graphical [web browsers](./Web_browser) display the `title` attribute of an [HTML](./Hypertext_Markup_Language) Don't bypass the redirect, so that the text is congruent with the image  [element](./Html_element) as a tooltip when a user hovers the pointer over that element; in such a browser, when hovering over Wikipedia images and hyperlinks a tooltip will appear.[[13]](./Tooltip#cite_note-:1-13)
