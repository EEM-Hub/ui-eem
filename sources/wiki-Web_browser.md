Software used to access websites 

  

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/b/ba/Safari_15.png/250px-Safari_15.png)](./File:Safari_15.png)A web browser ([Safari](./Safari_(web_browser))) displaying the [Wikipedia](./Wikipedia) [web page](./Web_page) 

A **web browser**, often abbreviated as **browser**, is an [application](./Application_software) for accessing [websites](./Website). When a [user](./User_(computing)) requests a [web page](./Web_page) from a particular website, the browser retrieves its [files](./Computer_file) from a [web server](./Web_server) and then displays the page on the user's screen. Browsers can also display content stored locally on the user's device.

 

Browsers are used on a range of devices, including [desktops](./Desktop_computer), [laptops](./Laptop), [tablets](./Tablet_computer), [smartphones](./Smartphone), [smartwatches](./Smartwatch), [smart televisions](./Smart_TV) and [consoles](./Video_game_console).[[1]](./Web_browser#cite_note-1) As of 2026[[update]](https://en.wikipedia.org/w/index.php?title=Web_browser&action=edit), the most used browsers worldwide are [Google Chrome](./Google_Chrome) (~69% [market share](./Market_share)), [Safari](./Safari_(web_browser)) (~16%), [Edge](./Microsoft_Edge) (~5%), [Firefox](./Firefox) (~2%), [Samsung Browser](./Samsung_Browser) (~2%), and [Opera](./Opera_(web_browser)) (~2%).[[2]](./Web_browser#cite_note-statcounter-2)[[3]](./Web_browser#cite_note-cloudflare-3) As of 2023, an estimated 5.4 billion people had used a browser.[[4]](./Web_browser#cite_note-4)

 

## Function

 Navigating to [English Wikipedia](./English_Wikipedia) using a web browser ([Firefox](./Firefox)) 

The purpose of a web browser is to fetch content and display it on the user's device.[[5]](./Web_browser#cite_note-5) This process begins when the user inputs a [Uniform Resource Locator](./Uniform_Resource_Locator) (URL), such as *`https://en.wikipedia.org/`*, into the browser's [address bar](./Address_bar). Virtually all URLs on [the Web](./World_Wide_Web) start with either *`http:`* or *`https:`* which means they are retrieved with the [Hypertext Transfer Protocol](./HTTP) (HTTP). For [secure mode](./HTTPS) (HTTPS), the connection between the browser and [web server](./Web_server) is [encrypted](./Encryption), providing a [secure](./Communications_security) and [private](./Information_privacy) data transfer.[[6]](./Web_browser#cite_note-6) For this reason, a web browser is often referred to as an HTTP client[[7]](./Web_browser#cite_note-7)[[8]](./Web_browser#cite_note-8) or a [user agent](./User_agent). Requisite materials, including text, [style sheets](./Style_sheet_(web_development)), [images](./Images), and other types of [multimedia](./Website#Multimedia_and_interactive_content), are [downloaded](./Downloaded) from the server. Once the materials have been downloaded, the web browser's [engine](./Browser_engine) (also known as a layout engine or rendering engine) is responsible for converting those resources into an interactive visual representation of the page on the user's device.[[9]](./Web_browser#cite_note-behindscene-9) Modern web browsers also contain separate [JavaScript engines](./JavaScript_engine) which enable more complex interactive applications inside the browser.[[10]](./Web_browser#cite_note-howBlinkWorks-10) A web browser that does not render a [graphical user interface](./Graphical_user_interface) is known as a [headless browser](./Headless_browser).

 

Web pages usually contain [hyperlinks](./Hyperlink) to other pages and resources. Each link contains a URL, and when it is [clicked](./Point_and_click) or [tapped](./Touchscreen), the browser navigates to the new resource. Most browsers use an internal [cache](./Web_cache) of web page resources to improve loading times for subsequent visits to the same page. The cache can store many items, such as large images, so they do not need to be downloaded from the server again. Cached items are usually only stored for as long as the web server stipulates in its HTTP response messages.[[11]](./Web_browser#cite_note-11)[[12]](./Web_browser#cite_note-12)

 

A web browser is not the same thing as a [search engine](./Search_engine), though the two are often confused.[[13]](./Web_browser#cite_note-13)[[14]](./Web_browser#cite_note-14) A search engine is a website that provides [links](./Hyperlink) to other websites and allows users to search for specific resources using a textual [query](./Web_query). However, web browsers are often used to access search engines, and most modern browsers allow users to access a default search engine directly by typing a query into the address bar.[[15]](./Web_browser#cite_note-15)

 

## History

 Main article: [History of the web browser](./History_of_the_web_browser) 

The first web browser, called [WorldWideWeb](./WorldWideWeb), was created in 1990 by Sir [Tim Berners-Lee](./Tim_Berners-Lee).[[16]](./Web_browser#cite_note-16)[[17]](./Web_browser#cite_note-17) He then recruited [Nicola Pellow](./Nicola_Pellow) to write the [Line Mode Browser](./Line_Mode_Browser), which displayed web pages on [dumb terminals](./Dumb_terminals).[[18]](./Web_browser#cite_note-:5-18) The [Mosaic](./Mosaic_(web_browser)) web browser was released in April 1993, and was later credited as the first web browser to find mainstream popularity.[[19]](./Web_browser#cite_note-19)[[20]](./Web_browser#cite_note-bloomberg-20) Its innovative [graphical user interface](./Graphical_user_interface) made the [World Wide Web](./World_Wide_Web) easy to navigate and thus more accessible to the average person. This, in turn, sparked the Internet boom of the 1990s, when the Web grew at a very rapid rate.[[20]](./Web_browser#cite_note-bloomberg-20) The lead developers of Mosaic then founded the [Netscape](./Netscape) corporation, which released the Mosaic-influenced [Netscape Navigator](./Netscape_Navigator) in 1994. Navigator quickly became the [most popular](./Usage_share_of_web_browsers#Older_reports_(pre-2000)) browser.[[21]](./Web_browser#cite_note-21)

 

[Microsoft](./Microsoft) debuted [Internet Explorer](./Internet_Explorer) in 1995, leading to a [browser war](./Browser_war) with Netscape. Within a few years, Microsoft gained a dominant position in the browser market for two reasons: it bundled Internet Explorer with its popular [Windows](./Microsoft_Windows) [operating system](./Operating_system) and did so as [freeware](./Freeware) with no restrictions on usage. The market share of Internet Explorer peaked at over 95% in the early 2000s.[[22]](./Web_browser#cite_note-searchenginejournal.com-22) In 1998, Netscape launched what would become the [Mozilla Foundation](./Mozilla_Foundation) to create a new browser using the [open-source software](./Open-source_software) model. This work evolved into the [Firefox](./Firefox) browser, first released by Mozilla in 2004. Firefox's market share peaked at 32% in 2010.[[23]](./Web_browser#cite_note-23) [Apple](./Apple_Inc.) released its [Safari](./Safari_(web_browser)) browser in 2003; it remains the dominant browser on Apple devices, though it did not become popular elsewhere.[[24]](./Web_browser#cite_note-browsershare-24)

 

[Google](./Google) debuted its [Chrome](./Google_Chrome) browser in 2008, which steadily took market share from Internet Explorer and became the most popular browser in 2012.[[25]](./Web_browser#cite_note-25)[[26]](./Web_browser#cite_note-26) Chrome has [remained dominant](./Usage_share_of_web_browsers) ever since.[[2]](./Web_browser#cite_note-statcounter-2) In 2015, Microsoft replaced Internet Explorer with [Edge [Legacy]](./Microsoft_Edge_Legacy) for the [Windows 10](./Windows_10) release.[[27]](./Web_browser#cite_note-27) In 2020, this legacy version was replaced by a new [Chromium](./Chromium_(web_browser))-based version of [Edge](./Microsoft_Edge).

 

Since the early 2000s, browsers have greatly expanded their [HTML](./HTML), [CSS](./CSS), [JavaScript](./JavaScript), and [multimedia](./Multimedia) capabilities. One reason has been to enable more sophisticated websites, such as [web apps](./Web_application). Another factor is the significant increase of [broadband](./Broadband) connectivity in [many parts](./List_of_sovereign_states_by_number_of_broadband_Internet_subscriptions) of the world, enabling people to access data-intensive content, such as [streaming](./Streaming_media) [HD video](./High-definition_video) on [YouTube](./YouTube), that was not possible during the era of [dial-up modems](./Dial-up_Internet_access).[[28]](./Web_browser#cite_note-28)

 

Starting in the mid-2020s, browsers with integrated [artificial intelligence](./Artificial_intelligence) (AI) capabilities, known as [AI browsers](./AI_browser), have become increasingly common. This includes both new entrants to the browser market, such as [Perplexity Comet](./Comet_(browser)) and [ChatGPT Atlas](./ChatGPT_Atlas), and established browsers that added AI features, such as Chrome with the [Gemini](./Gemini_(chatbot)) [chatbot](./Chatbot) and Edge with the [Copilot](./Microsoft_Copilot) chatbot.[[29]](./Web_browser#cite_note-29)[[30]](./Web_browser#cite_note-30)

 

## Features

 

The most popular browsers share many [features](./Software_feature). They automatically log users' [browsing history](./Web_browsing_history), unless the users turn off their browsing history or use the non-logging [private mode](./Private_browsing). They also allow users to set [bookmarks](./Bookmark_(digital)), customize the browser with [extensions](./Browser_extension), and [manage their downloads](./Download_manager)[[31]](./Web_browser#cite_note-31) and [passwords](./Password).[[32]](./Web_browser#cite_note-32) Some provide a sync service[[33]](./Web_browser#cite_note-33) and [web accessibility](./Web_accessibility) features.[[34]](./Web_browser#cite_note-34)

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/1/13/Chromium_%28web_browser%29.png/250px-Chromium_%28web_browser%29.png)](./File:Chromium_(web_browser).png)Traditional browser arrangement has [user interface](./User_interface) features above page content. 

Common [user interface](./User_interface) (UI) features:

 
- Allowing the user to have multiple [pages](./Web_page) open at the same time, either in different [windows](./Window_(computing)) or in different [tabs](./Tab_(interface)) of the same window.
- *Back* and *forward* buttons to go back to the previous page visited or forward to the next one.
- A *refresh* or *reload* and a *stop* button to reload and cancel loading the current page. (In most browsers, the stop button is merged with the reload button.)
- A *home* button to return to the [start page](./Home_page).
- An address bar to input the [URL](./URL) of a page and display it, and a search bar to input [queries](./Web_query) into a [search engine](./Search_engine). (In most browsers, the search bar is merged with the address bar.)

 

While [mobile browsers](./Mobile_browser) have similar UI features as [desktop](./Desktop_computer) versions, the limitations of the often-smaller [touch screens](./Touchscreen) require mobile UIs to be simpler.[[35]](./Web_browser#cite_note-35) The difference is significant for users accustomed to [keyboard shortcuts](./Keyboard_shortcut).[[36]](./Web_browser#cite_note-36) [Responsive web design](./Responsive_web_design) is used to create websites that offer a consistent experience across the desktop and mobile versions of the website and across varying screen sizes. The most popular desktop browsers also have sophisticated [web development tools](./Web_development_tools).[[37]](./Web_browser#cite_note-37)

 

Access to some web content — particularly [streaming services](./Streaming_media) like Netflix, Disney+, and Spotify — is restricted by [Digital Rights Management](./Digital_Rights_Management) (DRM) software. A web browser is able to access DRM-restricted content through the use of a [Content Decryption Module](./Content_Decryption_Module) (CDM) such as [Widevine](./Widevine). As of 2020, the CDMs used by dominant web browsers require browser providers to pay costly license fees, making it unfeasible for most independent open-source browsers to offer access to DRM-restricted content.[[38]](./Web_browser#cite_note-38)

 

## Browser market

 See also: [Usage share of web browsers](./Usage_share_of_web_browsers) 

[Google Chrome](./Google_Chrome) has been the dominant browser since the mid-2010s and currently has a 69% global market share on all devices.[[2]](./Web_browser#cite_note-statcounter-2) The vast majority of its [source code](./Source_code) comes from Google's [open-source](./Open-source_software) [Chromium](./Chromium_(web_browser)) project;[[39]](./Web_browser#cite_note-39) this code is also the basis for [many other](./Chromium_(web_browser)#Browsers_based_on_Chromium) browsers, including [Microsoft Edge](./Microsoft_Edge), currently in third place with about a 5% share,[[2]](./Web_browser#cite_note-statcounter-2) as well as [Samsung Internet](./Samsung_Internet) and [Opera](./Opera_(web_browser)) in fifth and sixth places respectively with approximately 2% market share each.[[2]](./Web_browser#cite_note-statcounter-2)

 

The other two browsers in the top four are made from different [codebases](./Codebase). [Safari](./Safari_(web_browser)), based on [Apple](./Apple_Inc.)'s [WebKit](./WebKit) code, is the second most popular web browser and is dominant on Apple devices, resulting in a 16% global share.[[2]](./Web_browser#cite_note-statcounter-2) [Firefox](./Firefox), in fourth place, with about 2% market share,[[2]](./Web_browser#cite_note-statcounter-2) is based on [Mozilla](./Mozilla)'s code. Both of these codebases are open-source, so a number of small niche browsers are also made from them.

### Market share by type of device

 

Prior to late 2016, the majority of web traffic came from desktop computers. However, [since then](./Usage_share_of_web_browsers#Crossover_to_smartphones_having_majority_share), mobile devices (smartphones) have represented the majority of web traffic.[[41]](./Web_browser#cite_note-StatCounterMobile2016-41) As of February 2025, mobile devices represent a 62% share of Internet traffic, followed by desktop at 36% and tablet at 2%.[[42]](./Web_browser#cite_note-StatCounterDeviceUsageRecent-42)

 

## Security

 Main article: [Browser security](./Browser_security) 

Web browsers are popular targets for [hackers](./Hacker), who exploit [security holes](./Vulnerability_(computing)) to steal information, destroy [files](./Computer_file), and partake in other [malicious](./Malware) activities. Browser vendors regularly patch these security holes, so users are strongly encouraged to keep their browser software updated. Other protection measures are [antivirus software](./Antivirus_software) and being aware of [scams](./Internet_fraud).[[43]](./Web_browser#cite_note-43)

 

### Privacy

 Further information: [Web tracking](./Web_tracking) 

During the course of browsing, [cookies](./HTTP_cookie) received from various [websites](./Website) are stored by the browser. Some of them contain login credentials or site preferences.[[44]](./Web_browser#cite_note-tom's_guide-44) However, others are used for tracking user behavior over long periods of time, so browsers typically provide a section in the menu for deleting cookies.[[44]](./Web_browser#cite_note-tom's_guide-44)

 

Some browsers have more proactive protection against cookies and trackers that limit their functionality and ability to track user behaviour.[[45]](./Web_browser#cite_note-45) Finer-grained management of cookies usually requires a [browser extension](./Browser_extension).[[46]](./Web_browser#cite_note-46) [Telemetry](./Telemetry_(software)) data is [collected](./Data_collection) by most popular web browsers, which can usually be opted out of by the user.[[47]](./Web_browser#cite_note-47)

 

A study from 2020 portrays that there are two tiers of browsers in terms of privacy: the privacy-focused ones ([Brave](./Brave_(web_browser)), [DuckDuckGo](./DuckDuckGo_Private_Browser), [LibreWolf](./LibreWolf), [Tor](./Tor_Browser),[Mullvad](./Mullvad_Browser), [Helium](./Helium_Browser?action=edit&redlink=1) and [Firefox-Focus](./Firefox_Focus)) perform better than popular ones (Chrome, [Firefox](./Firefox), and [Safari](./Safari_(web_browser))) and recommend the first ones.[[48]](./Web_browser#cite_note-:0-48) Blocking [fingerprinting](./Fingerprint_(computing)), cookies, [tracking](./Web_tracking) scripts, ads, etc. seems to explain that difference.[[48]](./Web_browser#cite_note-:0-48)
