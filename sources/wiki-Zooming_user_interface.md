Graphical interface allowing for image scaling 

 [![](//upload.wikimedia.org/wikipedia/commons/thumb/5/55/ZUI_example.png/330px-ZUI_example.png)](./File:ZUI_example.png)Example of a ZUI 

In [computing](./Computing), a **zooming user interface** or **zoomable user interface** (**ZUI**, pronounced zoo-ee) is a type of [graphical user interface (GUI)](./Graphical_user_interface) on which [users](./End-user_(computer_science)) can change the scale of the [viewed area](./Viewport) in order to see more detail or less, and browse through different [documents](./Electronic_document). Information elements appear directly on an infinite [virtual desktop](./Virtual_desktop) (usually created using [vector graphics](./Vector_graphics)), instead of in windows. Users can [pan](./Panning_(camera)) across the virtual surface in two dimensions and [zoom](./Page_zooming) into objects of interest. For example, as the user zooms into a text object, it may be represented as a small dot, then a page thumbnail, then a full-size page, and finally a magnified view of the page.

 

ZUIs use zooming as the main metaphor for browsing through [hyperlinked](./Hyperlink) or multivariate information. Objects present inside a zoomed page can, in turn, be zoomed themselves to reveal further detail, allowing for [recursive](./Recursion) [nesting](./Nesting_(computing)) and an arbitrary level of zoom.

 

Researchers have described the ZUI paradigm as a [Post-WIMP](./Post-WIMP) interface and potential successor to the traditional windowing GUI.[[1]](./Zooming_user_interface#cite_note-bederson-1)

 

The term ZUI was coined by [Franklin Servan-Schreiber](https://fr.wikipedia.org/wiki/Franklin%20Servan-Schreiber) while working at [Sony](./Sony) Research Laboratories, in partnership with [Ben Bederson](./Ben_Bederson) and [Ken Perlin](./Ken_Perlin) of [New York University](./New_York_University).[[2]](./Zooming_user_interface#cite_note-2)

 

## History

 

In 1962, [Ivan Sutherland](./Ivan_Sutherland) presented the first program for zooming through and creating graphical structures with constraints and [instancing](./Class_(programming)), on a CRT in his [Sketchpad](./Sketchpad) program.[[3]](./Zooming_user_interface#cite_note-3)

 

A more general interface was developed by the [Architecture Machine Group](./Architecture_Machine_Group) at MIT in the 1970s. Hand tracking, [touchscreen](./Touchscreen), [joystick](./Joystick), and [voice control](./Voice_user_interface) were employed to control an infinite plane of projects, documents, contacts, video, and interactive programs. One of the instances of this project was called Spatial Dataland.[[4]](./Zooming_user_interface#cite_note-4)

 

Another GUI environment of the '70s, which used the zooming idea was [Smalltalk](./Smalltalk) at [Xerox PARC](./PARC_(company)), which had infinite *desktops* (only later named such by [Apple Computer](./Apple_Inc.)), that could be zoomed in upon from a birds-eye view after the user had recognized a miniature of the window setup for the project.[*[citation needed](./Wikipedia:Citation_needed)*]

 

The longest running effort to create a ZUI has been the Pad++ project begun by [Ken Perlin](./Ken_Perlin), [Jim Hollan](./James_D._Hollan), and [Ben Bederson](./Ben_Bederson) at [New York University](./New_York_University)[[5]](./Zooming_user_interface#cite_note-perlin-fox-5)[[1]](./Zooming_user_interface#cite_note-bederson-1) and continued at the [University of New Mexico](./University_of_New_Mexico) under Hollan's direction. After Pad++, Bederson developed Jazz, then Piccolo,[[6]](./Zooming_user_interface#cite_note-6) and now Piccolo2D[[7]](./Zooming_user_interface#cite_note-7) at the [University of Maryland, College Park](./University_of_Maryland,_College_Park), which is maintained in [Java](./Java_(programming_language)) and [C#](./C_Sharp_(programming_language)).

 

More recent ZUI efforts include [Archy](./Archy_(software)) by the late [Jef Raskin](./Jef_Raskin), ZVTM developed at [INRIA](./INRIA) (which uses the Sigma lens[[8]](./Zooming_user_interface#cite_note-8) technique),[[9]](./Zooming_user_interface#cite_note-9) and the simple ZUI of the [Squeak](./Squeak) [Smalltalk](./Smalltalk) programming environment and language.

 

GeoPhoenix, a startup associated with the [MIT Media Lab](./MIT_Media_Lab), founded by Julian Orbanes, Adriana Guzman, and Max Riesenhuber, released a mass-marketed commercial Zoomspace in 2002–03 on the Sony [CLIÉ](./CLIÉ) [personal digital assistant](./Personal_digital_assistant) (PDA) handheld, with Ken Miura of Sony.[*[citation needed](./Wikipedia:Citation_needed)*]

 

In 2002, Pieter Muller extended the [Oberon System](./Oberon_(operating_system)) with a zooming user interface and named it *Active Object System* (AOS).[[10]](./Zooming_user_interface#cite_note-AOS-10) In 2005, due to copyright issues, it was renamed to *Bluebottle*, and in 2008, to *[A2](./A2_(operating_system))*.

 

In 2005, Franklin Servan-Schreiber founded Zoomorama, based on work he did at the Sony Research Laboratories in the mid-1990s. The Zooming Browser for Collage of High Resolution Images was released in Alpha in October 2007. Zoomorama's browser is all Flash-based. In 2010, project development ended, but many examples remain on the site.[*[citation needed](./Wikipedia:Citation_needed)*]

 

In 2006, [Hillcrest Labs](./Hillcrest_Labs) introduced the HoME television navigation system, the first graphical, zooming interface for television.[[11]](./Zooming_user_interface#cite_note-Derene-11)

 

In 2007, Microsoft's Live Labs released a zooming UI for web browsing called [Microsoft Live Labs Deepfish](./Microsoft_Live_Labs_Deepfish) for the Windows Mobile 5 platform.[*[citation needed](./Wikipedia:Citation_needed)*]

 

Apple's [iPhone](./IPhone) (premiered June 2007) uses a stylized form of ZUI, in which panning and zooming are performed through a [touch user interface](./Touch_user_interface) (TUI). A more fully realized ZUI is present in the [iOS](./IOS) home screen (as of [iOS 7](./IOS_7)), with zooming from the home screen into folders and, finally, into apps. The photo app zooms out from a single photo to moments, collections, and years, and similarly, the calendar app zooms out from day, month, and year views.[[12]](./Zooming_user_interface#cite_note-12) It is not a full ZUI implementation since these operations are applied to bounded spaces (such as web pages or photos) and have a limited range of zooming and panning.

 

From 2008 to 2010, [GNOME Shell](./GNOME_Shell) used a zooming user interface for virtual workspaces management.[[13]](./Zooming_user_interface#cite_note-13) This ZUI was eventually replaced by a different, scrolling-based design.[*[citation needed](./Wikipedia:Citation_needed)*]

 

[Prezi](./Prezi), a web-based presentation tool built on a single zoomable canvas, launched in 2009. Rather than build slides, users place content on an open surface and define a sequence of frames that the software navigates by panning, zooming, and rotating during playback. It was the first ZUI to reach mainstream adoption, surpassing 50 million users by 2014.[[14]](./Zooming_user_interface#cite_note-14)[[15]](./Zooming_user_interface#cite_note-15)

 

Stack Zooming, launched in 2010, was designed to navigate one-dimensional datasets such as time series by combining zooming and layering to keep the full dataset visible.[[16]](./Zooming_user_interface#cite_note-16) In 2012, PolyZoom extended the Stack Zooming concept to two-dimensional spaces.[[17]](./Zooming_user_interface#cite_note-17)

 

The [Miro collaboration platform](./Miro_(collaboration_platform)), which uses a zooming user interface, was released in 2011 as *RealtimeBoard* and rebranded to *Miro* in 2019. In 2022, it reported 40 million users.[*[citation needed](./Wikipedia:Citation_needed)*]

 

In 2017, bigpictu.re offered an infinite (pan and zoom) notepad as a web application based on one of the first ZUI open-source libraries.[[18]](./Zooming_user_interface#cite_note-bigpicturejs-18)

 

In 2017, Zircle UI was released. It is an open-source UI library that uses zoomable navigation and circular shapes.[[19]](./Zooming_user_interface#cite_note-19)

 

## Types of zooming

 

Zooming interfaces have implemented several types of zooming behaviors, including:

 
- **Geometric** zooming scales objects in direct proportion to the zoom level,[[1]](./Zooming_user_interface#cite_note-bederson-1) and is the most common zoom method in zoomable user interfaces.[[20]](./Zooming_user_interface#cite_note-hornbaek-20)
- **Semantic** zooming changes the representation of an object based on scale, rather than simply resizing it.[[5]](./Zooming_user_interface#cite_note-perlin-fox-5)[[21]](./Zooming_user_interface#cite_note-21) In Pad's multiscale calendar, zooming out shows a grid of years while zooming in reveals individual days;[[5]](./Zooming_user_interface#cite_note-perlin-fox-5) in Pad++, a digital clock shows hours and minutes at normal size, seconds when zoomed in, and just the hour when zoomed out.[[1]](./Zooming_user_interface#cite_note-bederson-1)
- **Fisheye** zooming preserves the area of focus in full detail while compressing surrounding elements more with distance.[[22]](./Zooming_user_interface#cite_note-furnas-22) Furnas demonstrated the technique using a botanical taxonomy, in which nodes far from the current focus were removed entirely from the display when their degree of interest fell below a threshold.[[22]](./Zooming_user_interface#cite_note-furnas-22) 
- **Logical fisheye** zooming shows the focus in full detail and filters everything else by a degree-of-interest score based on structural distance rather than screen position.[[22]](./Zooming_user_interface#cite_note-furnas-22)[[23]](./Zooming_user_interface#cite_note-23) Implemented in Furnas's C program viewer, which shows the current line in full detail while removing distant code below the degree-of-interest threshold.[[22]](./Zooming_user_interface#cite_note-furnas-22)
- **Graphical fisheye** zooming distorts coordinate space so nearby elements enlarge and distant ones compress, with each element's pre-assigned importance also shaping how much space and detail it receives.[[24]](./Zooming_user_interface#cite_note-sarkar-brown-24) Implemented in Sarkar & Brown's interactive graph browser.[[24]](./Zooming_user_interface#cite_note-sarkar-brown-24)
- **Intelligent** zooming combines fisheye zooming with adaptive presentation; the system determines the most appropriate display format for each element.[[25]](./Zooming_user_interface#cite_note-bartram-25) Implemented in Bartram et al.'s network supervisory control interface for telecommunications.[[25]](./Zooming_user_interface#cite_note-bartram-25)
- **Semantic fisheye** zooming extends fisheye views by using semantic distance metrics, preserving the area of focus in full detail and de-emphasizing other elements based on how closely each element relates to the current task, rather than by physical distance on-screen.[[26]](./Zooming_user_interface#cite_note-janecek-pu-26) Implemented in a tabular flight itinerary browser,[[26]](./Zooming_user_interface#cite_note-janecek-pu-26) and an experimental [VUE](./Visual_Understanding_Environment)-based concept map interface.[[27]](./Zooming_user_interface#cite_note-27)

- **Topological** zooming uses graph structure to calibrate detail. The focus node renders at full resolution; everything farther out is replaced with coarser, precomputed approximations of the graph.[[28]](./Zooming_user_interface#cite_note-gansner-28) Implemented in Gansner et al.'s topological zooming tool for visualizing large graphs.[[28]](./Zooming_user_interface#cite_note-gansner-28)
